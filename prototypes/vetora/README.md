# Vetora — прототипы агрегатора и CRM

Статический сайт из двух независимых, самодостаточных HTML-прототипов.

| Путь | Прототип | Версия |
| --- | --- | --- |
| `/` | Агрегатор Vetora, поиск и запись | `Vetora_Iteration_35_Booking_Flow.html` |
| `/crm/` | Портал клиники, рабочие области врача, администратора и руководителя | `Vetora_CRM_Iteration_07_Clinic_Portal.html` |

## Развёртывание

Не требуется сборка, серверное приложение или установка зависимостей. Для GitHub Pages можно выбрать ветку публикации и каталог `/ (root)`; для другого статического хостинга — корень репозитория.

Ветки и изменения прототипов версионируются в Git. Файл `index.html` — актуальная версия агрегатора, `crm/index.html` — актуальная версия CRM. Следующие итерации обновляют только соответствующую страницу.

## Ограничения

- Это интерактивные прототипы с браузерным хранением данных, а не боевые сервисы.
- Интеграция с агрегатором и серверная проверка ролей не подключены.
- В CRM тестовый аккаунт врача привязан к Анне Смирновой; это условие не заменяет авторизацию.
