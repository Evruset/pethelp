# VetHelp Owner V50 — Behavioral experiment v1

Изменения сделаны поверх исходного V50 без замены основного визуального языка.

## Что изменено

- **Главная:** immediate value preview — подходящие варианты, время, цена и отсутствие необходимости звонить.
- **Каталог:** пользователь явно выбирает приоритет «сегодня / цена / ближе / уверенность»; вместо непрозрачного `care-fit` показано объяснение «почему подходит».
- **Карточка питомца:** accumulated value — данные вводятся один раз и используются в следующих записях.
- **Pet Diary:** Give-to-Get — документ загружается один раз, остаётся с питомцем и может быть выборочно передан врачу.
- **Проверка записи:** WIIFM после отправки — не нужно звонить и узнавать статус вручную.
- **Alternative slot:** убрано давление таймера/«заморозки»; подчёркнуто, что врач, услуга и данные уже сохранены, меняется только время.

## Принципы

Give-to-Get · WIIFM · autonomy/control · saved effort · endowed progress · positive closure · explainable recommendation.

## Unified UX/UI pass

Поверх behavioral-эксперимента добавлен единый owner/aggregator guideline:

- B2C определяется как fast decision interface, а не dense CRM;
- главная уменьшена по масштабу, первый viewport быстрее показывает полезное действие;
- каталог уплотнён вокруг «кто / когда / сколько / где / почему подходит»;
- карточка клиники получила один верхний decision summary;
- повторяющиеся price/trust/consent блоки на этапе выбора скрыты;
- выбор врача стал компактнее;
- базовая запись сокращена до 2 шагов и больше не требует отдельного insurance-step;
- review заявки оставляет один truthful status вместо нескольких повторов;
- alternative slot очищен от внутренних backend/fencing объяснений;
- mobile остаётся одношаговым task-flow, а не уменьшенным desktop.
