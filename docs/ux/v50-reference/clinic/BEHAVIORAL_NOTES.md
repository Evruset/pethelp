# VetHelp Clinic V50 — Behavioral experiment v1

Изменения сделаны поверх standalone Clinic V50.

## Что изменено

- **Сводка:** разный WIIFM по роли — ресепшен, врач, администратор.
- **Расписание:** показано, зачем открывать/закрывать слот и какой результат это даёт владельцу.
- **Записи:** рядом с действием показан эффект: подтверждение автоматически становится понятным статусом владельца.
- **Документы пациента:** «загрузить один раз» вместо ручной пересылки после визита.
- **Приём:** positive closure — после завершения история обновлена, результат можно сразу передать владельцу.
- **Услуги:** публикация объясняется через полезный результат: услуга + цена + слот = готовый вариант в поиске.
- **Профиль клиники:** прогресс готовности к самостоятельной онлайн-записи.
- **Настройки:** формулировки объясняют, какую ручную работу снимает настройка.
- **Toast-feedback:** сообщает не технический факт изменения, а его операционный результат.
