# Wave 4 Owner discovery evidence

This bounded machine-evidence package was captured from the final production
Expo Web source while the Owner journey used the local BFF, Backend, and
PostgreSQL. It covers all 12 required discovery states with 19 screenshots
across five viewports. `capture-run.json` records source and image hashes,
overflow checks, axe serious/critical checks, and keyboard focus evidence.

Verify from the repository root:

```sh
node scripts/visual/verify-wave4-owner-discovery-evidence.mjs
```

This is not physical-device, signed-build, UAT, pilot-clinic, deployment, or
production-booking evidence.
